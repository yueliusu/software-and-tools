## 官方商店

<a id="tool-chrome-应用商店"></a>

### Chrome 应用商店

Google Chrome 浏览器的**官方插件市场**，提供了数以万计的扩展程序和应用。用户可以在这里找到各种功能插件，包括广告拦截、密码管理、开发者工具、生产力工具等。

**网址： [https://chrome.google.com/webstore](https://chrome.google.com/webstore)**

<a id="tool-edge-附加组件"></a>

### Edge 附加组件

Microsoft Edge 浏览器的官方扩展市场，提供了丰富的扩展程序和应用。由于 Edge **基于 Chromium 引擎**，许多 Chrome 扩展也可以直接在 Edge 中使用。

**网址：[https://microsoftedge.microsoft.com/addons/Microsoft-Store](https://microsoftedge.microsoft.com/addons/Microsoft-Store)**

<a id="tool-firefox-扩展"></a>

### Firefox 扩展

Mozilla Firefox 浏览器的官方插件商店，提供各种各样的扩展和主题。与其他浏览器不同，Firefox **强调隐私和安全**，因此很多扩展聚焦于这些领域，例如追踪保护、广告拦截和加密工具。

**网址：[https://addons.mozilla.org](https://addons.mozilla.org)**

### 极简插件
