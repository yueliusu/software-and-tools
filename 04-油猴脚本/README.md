## 网页与搜索

<a id="tool-ac-baidu"></a>

### AC-baidu - 重定向优化百度搜狗谷歌必应搜索

这个脚本主要是用来优化搜索引擎页面的样式，支持百度、必应、谷歌等常见搜索网站。对于经常用搜索引擎找资料的人来说，页面看起来会更清爽，体验也会顺手一些。**如果你平时搜索比较多，这种增强类脚本还是挺实用的。**

**安装地址：[https://greasyfork.org/zh-CN/scripts/14178](https://greasyfork.org/zh-CN/scripts/14178)**

<a id="tool-聚合搜索引擎切换导航"></a>

### 聚合搜索引擎切换导航（桌面、移动端）

这个脚本功能比较丰富，不只是搜索引擎切换，还支持页面底部快捷栏、GitHub 搜索结果增强、拖拽排序、自定义引擎管理和快捷搜索等，同时还对移动端做了优化。**适合经常在多个搜索引擎之间切换的人，用起来会比手动来回切方便很多。**

**安装地址：[聚合搜索引擎切换导航](https://greasyfork.org/zh-CN/scripts/513481-聚合搜索引擎切换导航-github搜索结果增强-移动端优化)**

<a id="tool-自动无缝翻页"></a>

### 自动无缝翻页

这个脚本可以把下一页内容直接加载到当前页面底部，效果有点类似无限滚动，不需要再手动点“下一页”。**对于论坛、博客、搜索结果这类分页比较多的网站来说会很舒服，连续浏览体验会好很多。**

**安装地址：[https://greasyfork.org/zh-CN/scripts/419215](https://greasyfork.org/zh-CN/scripts/419215)**

## 网盘辅助

<a id="tool-linkswift"></a>

### LinkSwift

这个脚本的主要功能是解析百度网盘、阿里云盘、夸克网盘、天翼网盘等常见网盘的下载链接，并且支持推送到 IDM 或 Aria2。**如果你平时经常折腾下载，这类脚本非常实用，省去了自己找直链和手动复制的麻烦。**

**安装地址：[LinkSwift](https://github.com/hmjz100/LinkSwift)**

<a id="tool-网盘有效性检查"></a>

### 网盘有效性检查

这个脚本可以自动识别网盘链接状态、自动填写密码并跳转。**有些分享链接失效没失效，平时还得自己点进去试，这个脚本能省掉不少重复操作。**

**安装地址：[https://greasyfork.org/zh-CN/scripts/439266](https://greasyfork.org/zh-CN/scripts/439266)**
